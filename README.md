## 🌟 Overview
Welcome to the **Autonomous 3D Video Frame**. Built with the sleek glassmorphism aesthetic of modern web components, this layout infinitely floats and tilts in a full 3D perspective space. The corporate video is seamlessly framed within a glossy card, complete with interactive background controls and a stunning particle environment. 

This component instantly elevates any promotional video into a highly engaging, interactive web experience.

---

## 🚀 Instant Quick Start (One Command)
> [!TIP]
> **Zero configuration required!** You can launch this software instantly using our magic start scripts.

### 🪟 For Windows
Simply double-click the `start.bat` file in your project folder, or run this in your terminal:
```cmd
start.bat
```

### 🍏 For Mac / Linux
Run the setup shell script in your terminal:
```bash
./start.sh
```

*(These scripts will automatically install all necessary dependencies and launch the live application directly in your browser!)*

## 🎬 How to Use Your Own Video
Displaying your own company or promotional video inside this premium 3D frame takes less than 10 seconds.

> [!IMPORTANT]
> Ensure your video is in `.mp4` format for the best web compatibility.

1. Locate your new video file on your computer.
2. Rename it exactly to **`ogdcl_scroll.mp4`**.
3. Drag and drop it into the `public/` folder of this project, replacing the existing file.
4. Refresh your browser, and your custom video will instantly begin playing inside the floating 3D glass card!
